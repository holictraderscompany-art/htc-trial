# Foundation Boundaries

- **T01 — Repository & System Foundation:** repository structure, architecture boundaries, conventions, and security baseline.
- **T02 — Database & Core Data Foundation:** future database and core data scope.
- **T03 — Authentication & Role Authorization Foundation:** future identity and role authorization scope. The founder/owner/admin identity is `holictraderscompany@gmail.com`; all other authenticated identities are `USER`.
- **T04 — API, Access Control & Release Foundation:** future API, access-control, and release scope.
- **T05 — Foundation Validation & Test Layer:** future validation and testing scope.

T01 MUST NOT implement T02–T05. T01 only documents future direction; it does not implement database, authentication, authorization, API, release, or test runtime functionality.
