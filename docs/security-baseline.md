# Security Baseline

- Never commit secrets.
- Never hardcode credentials.
- Never expose service-role credentials.
- Apply least privilege.
- Handle configuration securely.
- Authorization must not rely on frontend-only checks.
- Future authorization must be server-side.
- Minimize sensitive data.
- Require security review for T02, T03, T04, and T05.

T01 implements no runtime security code, authentication, authorization, database, API, or configuration system. The founder/admin identity documented for future work is `holictraderscompany@gmail.com`. The trial period is September–December 2026; official curriculum begins in January 2027.
