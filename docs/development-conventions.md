# Development Conventions

- One task = one scope.
- Use minimal implementation.
- Do no hidden work.
- Do not add speculative features.
- Do not add unnecessary dependencies.
- Do not expand scope.
- Validate before completion.

The controlled workflow is: build → test → report → review → approval → commit/push.

Commits, pushes, and deployments require explicit human approval. There is no automatic commit, automatic push, or automatic deployment.
