# Holic Traders Company (HTC)

## Repository purpose

This repository contains the framework-independent HTC System Foundation. HTC's core is education, learning, knowledge, and community, supported by content, automation, analytics, and monetization. Its philosophy is Educate, Empower, Elevate; its user journey is Learn, Grow, Rise.

The System Foundation is shared infrastructure and documentation for future HTC work. It is separate from both the future Public/User Application and the future Founder/Admin Application.

## Group 01 and T01

Group 01 establishes the foundation repository. T01 creates only the repository structure, boundaries, conventions, and security baseline. T01 contains no application UI and no runtime implementation.

Future application layers may depend on the Foundation; the Foundation must not depend on future application presentation layers.

## Sequence

- T01 — Repository & System Foundation
- T02 — Database & Core Data Foundation
- T03 — Authentication & Role Authorization Foundation
- T04 — API, Access Control & Release Foundation
- T05 — Foundation Validation & Test Layer

T01 documents the trial boundary: September–December 2026 is validation only, with no actual lessons, curriculum, modules, quizzes, or public learning dashboard. Official curriculum begins in January 2027.
